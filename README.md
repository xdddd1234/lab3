# Лабораторна робота №3 — Sequence Diagrams

## Тема
Моделювання взаємодії об'єктів у Library Management System.

## Мета роботи
Створити sequence-діаграми для UC-03 «Видача книги» з лабораторної №2.

## Сценарії
- SC-01 — Успішна видача книги.
- SC-02 — Книга вже видана.
- SC-03 — Неправильна дата повернення.
- SC-04 — Читач не зареєстрований.

Для кожного сценарію буде окрема PlantUML-діаграма та SVG-рендер.

## Зв'язок із попередніми роботами
- Лабораторна №1 — ER-модель бібліотеки.
- Лабораторна №2 — EARS-вимоги, User Stories, Gherkin та Use Case Diagram.

## Використання AI
AI використовується для аналізу сценаріїв, пошуку помилок та перевірки діаграм. Остаточні рішення й перевірку результатів виконує студент.
